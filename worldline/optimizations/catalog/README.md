# BetaEnergistics Optimization Catalog

Each UTF-8 `.properties` file is named after one stable `betaenergistics.*`
optimization ID. Records describe project-owned implementation facts and use
`tracking=symbol`, so no annotation dependency enters BetaEnergistics source or
release artifacts.

An implementation, default, risk, rollback, or evidence change must update its
record in the same repository change. Candidate records remain disabled until
their declared behavioral boundaries have portable Worldline evidence.
