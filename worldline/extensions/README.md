# Worldline Extension Manifests

BetaEnergistics-owned Worldline extension manifests belong under this
directory:

```text
worldline/extensions/<id>/manifest.properties
```

Copy `TEMPLATE.properties` into an `<id>` directory only when BetaEnergistics
binds real overlay sites to existing Worldline catalog roles. Host-only TestKit
specifications are tests, not extension manifests, and remain under
`tests/worldline/`.

Optimization records belong in `worldline/optimizations/catalog/`.
